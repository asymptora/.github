# Asymptora

Software engineering with the rigor that production systems demand.

We build Java backend systems with a focus on domain modeling, code quality, and architecture that withstands scrutiny, not just demonstration.

## How We Work

Each product starts with a documented specification, with requirements and progression criteria defined before implementation. Work does not move forward based on a perception of quality. It moves forward when the established criteria are met.

Every significant engineering decision is documented, along with the reasoning behind it, including the alternatives that were rejected. Every mistake is analyzed and turned into documented knowledge.

We operate our own servers: a provisioned and maintained homelab used to run, test, and maintain in production what we build.

Asymptora is built and maintained by [Higor Cazuza](https://github.com/higorcazuza81) and [Janaína Cazuza](https://github.com/janainacazuza), software engineers.
